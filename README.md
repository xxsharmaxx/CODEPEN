# 💻 Online Code Compiler

## 📌 About
This project is a simple **online code compiler interface** built using **HTML, CSS, and JavaScript**.  
It provides a clean editor-like layout where users can write code, run it, and view the output directly in the browser.

---

## 🚀 Features
- Write code in the editor
- Run code instantly
- Display output in real time
- Simple and user-friendly interface
- Built only with frontend technologies

---

## 🛠 Tech Stack
- **HTML** – structure of the compiler
- **CSS** – styling and layout
- **JavaScript** – logic and interactivity
